# NovelForge V2 OmniRoute Handoff Pack

This ZIP is an architecture and implementation handoff for coding
agents.

Start with `START-HERE.md`. Do not begin implementation by reading files
randomly.

The pack intentionally separates permanent invariants from detailed
domain specifications so multiple LLMs can collaborate with bounded
context.

Current gateway baseline: OmniRoute through a provider-independent
adapter.

This is a design/handoff pack, not an already implemented NovelForge
application.
