# Administration Specification

## Gateway dashboard
Show:
- gateway status
- latency
- error rate
- model list
- last health check
- routing configuration
- usage

## Agent dashboard
Manage:
- agents
- versions
- system instructions
- assigned skills
- references
- knowledge policies
- model profile

## Skill dashboard
Manage:
- reusable skills
- versions
- descriptions
- prompts/instructions
- compatibility metadata

## Reference dashboard
Manage:
- source
- scope
- versions
- indexing status
- permissions
- spoiler classification

## Workflow dashboard
Manage:
- workflow versions
- nodes
- edges
- validation
- activation
- execution history

## Evaluation dashboard
Show:
- generation volume
- latency
- failure rate
- token/usage data
- continuity evaluations
- style evaluations
- human feedback
