## Writer workspace
The writer workspace should make the novel's structured knowledge visible without overwhelming the editor.

Suggested layout:
- left: chapter/scene navigation
- center: Tiptap editor
- right: AI assistant/context/continuity panel

## AI assistant
Support:
- inline actions
- chapter generation
- scene generation
- rewrite
- continuity check
- lore check
- character voice check
- summarize
- brainstorm

## Reader
Reader should support:
- chapter navigation
- bookmarks
- follows
- comments
- reading progress
- spoiler-safe content
- responsive typography

## Admin
Admin should expose:
- gateway health
- model availability
- routing policy
- agent versions
- skill versions
- reference versions
- workflow versions
- AI usage
- evaluation results
- audit logs
