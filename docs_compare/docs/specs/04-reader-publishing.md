# Reader and Publishing Specification

## Publishing
A chapter moves through:
DRAFT
→ IN_REVIEW
→ SCHEDULED
→ PUBLISHED

It may later become:
UNPUBLISHED or ARCHIVED

## Reader access
Readers should only see content explicitly published.

Reader AI features, if added, must obey spoiler boundaries.

## Social features
Support:
- bookmarks
- follows
- likes
- comments
- notifications
- reading progress

## Import/export
Import:
- TXT
- Markdown
- PDF
- DOCX

Export:
- Markdown
- TXT
- DOCX
- PDF
- EPUB

Imports should be treated as source material until normalized and approved.
