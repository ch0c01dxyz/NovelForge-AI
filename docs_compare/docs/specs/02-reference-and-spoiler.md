# Reference and Spoiler Specification

## Reference scopes
References can be:
- global
- genre
- agent
- novel
- task

Examples:
- writing craft
- genre conventions
- terminology
- author style guide
- world research
- imported notes

## Reference versioning
Every important reference should be versioned and traceable.

## Spoiler controls
Every knowledge item that can leak future information should have a spoiler boundary.

Reader retrieval must be constrained by:
- novel
- published chapter
- available-from chapter
- reader mode

Author/editor retrieval can have broader access according to permissions.

## Important rule
Never infer that because information exists in the database it is safe to show to a reader.
