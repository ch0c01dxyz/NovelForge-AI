# Core Workflows

## Chapter generation

Request -\> resolve approved outline -\> retrieve structured state -\>
retrieve relevant memory -\> Scene Planner -\> Character/Relationship
context -\> Chapter Writer -\> Continuity/Lore/Knowledge review -\>
Rhythm/outline review -\> persist generation -\> extract candidate
facts/state changes -\> author/policy approval -\> canonical commit -\>
memory consolidation.

## Canon mutation

Author change -\> impact analysis -\> risk classification -\>
optional/required checkpoint -\> Story Transaction -\> mutation -\>
validators -\> derived invalidation -\> commit -\> rebuild jobs.

## Bulk rewrite

Select scope -\> impact analysis -\> mandatory checkpoint -\> branch
recommended -\> generation jobs -\> review -\> compatibility scan -\>
explicit apply/merge.

## What-If

Create simulation branch -\> apply hypothetical mutation -\> simulate
affected outline/state -\> report consequences -\> discard or propose
merge. Never mutate main automatically.

## Endgame

Activate endgame horizon -\> build resolution ledger -\> identify
critical debt -\> plan final saga -\> validate
character/relationship/world resolution -\> final conflict/aftermath -\>
callbacks -\> epilogue/legacy -\> closure check.

## Memory consolidation

Chapter accepted -\> structured event extraction -\> candidate canon -\>
approved changes -\> chapter memory -\> arc state update -\>
character/relationship/timeline/thread updates -\> global
projections/index updates.
